# Portfolio brief — ARCANA LAB v0.2

## Project summary

A typographic, diagram-led Streamlit application combining a sequential 93-lesson tarot curriculum, a four-spread reflective reading workspace, a local structured database and a descriptive analytics dashboard. Its purpose is to demonstrate applied data modeling, Python, SQL, analytics, visualization and information design through a coherent personal learning product.

## Product workflow

**LEARN → PRACTICE → RECORD → OBSERVE**

- Learn: eight ordered modules, 93 lessons and progress tracking, including one lesson for every card in the 78-card dataset.
- Practice: four spread structures with position diagrams, compact keyword-led outputs, personal interpretation, synthesis and an action.
- Observe: descriptive analytics for course completion, study performance, reading activity, card/suit distribution and recorded themes.
- Data: local SQLite, schema, reference CSVs, database backup and personal-record exports.

## Skills demonstrated

- **Data modeling:** normalized 78-card reference dataset, stable IDs, correspondence metadata and lesson-progress records.
- **Database engineering:** SQLite schema, foreign keys, indexes, views, CRUD operations and schema initialization.
- **Python:** curriculum generation, card drawing without replacement, interpretation templates, data access and validation.
- **SQL:** joins, aggregations, data exports and descriptive queries.
- **Analytics:** study progress, retrieval accuracy, recorded themes, suit frequencies and life-domain distributions.
- **Visualization:** Plotly charts and custom SVG spread maps with a restrained, category-aware visual language.
- **Information design:** typographic hierarchy, metadata labels, position-first interpretation and compact learning content.
- **Product thinking:** sequential course architecture, user-led interpretation, privacy boundaries and backup/export flows.
- **Testing:** tests for deck integrity, unique draws, curriculum coverage, sequence, database initialization and lesson-progress persistence.

## Demonstration metrics

Use only records generated by actual use. Examples include unique cards studied, module completion, quiz accuracy, recall ratings, review intervals, readings by life domain, suit distribution, readings with an insight/action and completed follow-ups.

## Limitations

ARCANA LAB is a single-user prototype and a symbolic reflection tool, not a clinical instrument, predictive system or validated psychological assessment. Card correspondences are tradition-specific. Streamlit Community Cloud local storage is not durable; add authentication and managed persistence before relying on hosted personal records.
